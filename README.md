# Verification-of-UART-protocol-using-System-Verilog

The UART (Universal Asynchronous Receiver-Transmitter) protocol is a widely used asynchronous serial communication protocol that enables full-duplex data transfer between digital systems. Unlike synchronous protocols, UART does not require a separate clock signal; instead, both transmitter and receiver agree upon a predefined baud rate for communication. Data is transmitted in frames consisting of a start bit, 8 data bits (LSB first), optional parity bit, and one or more stop bits. UART is simple, cost-effective, and commonly used in embedded systems, microcontrollers, debugging interfaces, and PC-to-device communication.

This project implements a complete UART design in SystemVerilog, including a baud rate generator, transmitter (TX), receiver (RX), and loopback functionality. The design was verified using a modular testbench architecture with driver, monitor, reference model, and scoreboard components to ensure correct frame transmission and reception. The implementation supports proper handshake signals such as busy and ready, and was validated through multiple randomized test cases to confirm reliable serial data transfer.
